# 사단법인 화성연구회 홈페이지

수원화성의 연구, 보존, 홍보를 하는 사단법인 화성연구회의 홈페이지입니다. 별도 서버 없이 GitHub Pages로 공개할 수 있는 정적 사이트입니다.

## 메뉴 구성

| 폴더 | 페이지 |
|---|---|
| `/` | 처음 화면(`index.html`), 이미지 출처(`credits.html`), 개인정보처리방침(`privacy.html`), `404.html` |
| `about/` | 인사말, 설립 목적, 연혁, 역대 이사장, 수상, 찾아오시는 길 |
| `programs/` | 주요 사업, 대표 행사(성신사 고유제, 명패봉안문화제, 낙성연), 행사 기록 |
| `participate/` | 행사 달력, 프로그램 신청(예시), 신청 내역 확인(예시), 회원·후원·자원봉사 |
| `hwaseong/` | 수원화성 개요, 축성 이야기와 연표, 시설물 지도, 화성행궁·화령전, 기록유산과 관련 유산, 용어 사전 |
| `tour/` | 관람 정보, 답사 코스 추천, 축제 일정 |
| `news/` | 공지사항, 언론 보도, 자료실 |

## 파일 구조

```
assets/
  css/style.css        공통 스타일
  js/data.js           시설물, 연표, 행사, 코스, 용어, 이미지 정보(내용 수정은 대부분 여기서)
  js/site.js           머리글·바닥글, 메뉴, 사진, 연표, 탭, 용어 사전
  js/fortress.js       성곽 개념도(SVG)
  js/participate.js    달력, 신청서, 신청 내역 확인
  favicon.svg
```

머리글과 바닥글은 `site.js`가 모든 페이지에 똑같이 넣습니다. 메뉴를 바꾸려면 `site.js`의 `HS.nav`를 고치세요.

## GitHub Pages로 공개하기

1. GitHub에서 새 저장소를 만듭니다(예: `hwaseong-society`). 공개(Public)로 설정합니다.
2. 이 폴더의 파일을 모두 저장소에 올립니다.
   ```
   git init
   git add .
   git commit -m "화성연구회 홈페이지 첫 공개"
   git branch -M main
   git remote add origin https://github.com/계정이름/hwaseong-society.git
   git push -u origin main
   ```
3. 저장소의 **Settings > Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 고르고 저장합니다.
4. 몇 분 뒤 `https://계정이름.github.io/hwaseong-society/`에서 열립니다.

모든 링크를 상대 경로로 만들었기 때문에 저장소 이름이 무엇이든 그대로 작동합니다. 도메인을 따로 연결하려면 Settings > Pages의 Custom domain에 주소를 넣으세요.

## 운영 전에 바꿀 내용

- **[대괄호]로 표시한 자리**: 사무실 주소, 전화, 이메일, 고유번호, 회비, 후원 계좌, 임원 명단
- **인사말**: `about/index.html`의 예시 원고를 이사장 확인 원고로 교체
- **예시 일정**: `data.js`의 `HS.events`에서 `kind: "sample"` 항목을 실제 프로그램으로 교체
- **확인 필요 항목**: 사단법인 출범 연도(2000년/2001년), 제4~8대 이사장, 축성 장인 수(1,821명/2,197명), 2025년 행사 기록
- **개인정보처리방침**: `privacy.html`은 예시 문안입니다

## 일정 추가하는 법

`assets/js/data.js`의 `HS.events`에 한 줄을 더합니다.

```js
{ id: "own-2027-goyuje", kind: "own", apply: true,
  start: "2027-01-09", end: "2027-01-09", time: "11:00",
  title: "2027 신년 성신사 고유제", place: "팔달산 성신사",
  cap: 80, taken: 0, fee: "무료", note: "고유제 후 신년회" }
```

- `kind`: `own`(연구회 행사), `ext`(외부 행사), `sample`(예시)
- `apply: true`이면 신청서 목록에 나옵니다. 이때 `cap`(정원)을 꼭 적으세요.

## 참가 신청 기능에 대해

지금의 신청서, 신청 내역 확인, 회원 가입 신청은 **예시**입니다. 입력한 내용은 방문자 브라우저(localStorage)에만 저장되고 사무국으로 전송되지 않습니다.

실제로 접수하려면 다음 가운데 하나를 고르세요.

1. **외부 신청서 연결**: Google 설문지나 네이버 폼을 만들고, 신청 버튼 링크를 그 주소로 바꿉니다. 가장 간단합니다.
2. **접수 저장소 연결**: Firebase, Supabase 같은 서비스로 저장소를 만들고 `assets/js/participate.js`의 `saveApplication`, `findApplications`, `removeApplication` 함수를 그 서비스 호출로 바꿉니다. 정원 계산과 화면은 그대로 쓸 수 있습니다.

개인정보를 실제로 받기 전에 개인정보처리방침을 완성하고, 확인 번호 대신 휴대전화 인증을 쓰는 방식을 검토하세요.

## 이미지

사진은 위키미디어 공용(Wikimedia Commons)의 자유 이용 사진과 퍼블릭 도메인 도판을 위키미디어 서버에서 불러옵니다. 저작자와 라이선스는 `credits.html`에 모두 적었고, 사진 아래에도 표시합니다.

- CC BY, CC BY-SA 사진은 저작자와 라이선스 표시를 지우지 마세요.
- 연구회가 직접 찍은 사진으로 바꾸려면 `assets/img/`에 파일을 넣고 `data.js`의 해당 항목에 `local: "assets/img/파일명.jpg"`를 적습니다.
- 사진이 없는 시설물은 ‘사진 준비 중’으로 나옵니다. `HS.facilities`의 `img` 값에 이미지 키를 적으면 연결됩니다.
- 언론 보도 사진은 저작권이 있어 허락 없이 쓸 수 없습니다.

## 시설물 지도에 대해

성곽 개념도는 시설물의 순서와 대략의 방향만 보여 주는 그림입니다. 실제 지도처럼 쓰려면 국가유산청 공간정보나 수원시 자료에서 시설물 좌표를 받아 Leaflet 같은 지도 라이브러리로 바꾸는 것을 권합니다.
